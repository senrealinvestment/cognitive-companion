# teach-me

Grok skill for **long-term learning and career-long teaching ability**.

Uses verified adult-learning methods: scaffolding, active recall, spaced repetition, elaborative interrogation, interleaving, Feynman teach-back, and corrective feedback.

## Install (local Grok)

Copy or clone this folder to:

```text
~/.grok/skills/teach-me/
```

Required file: `SKILL.md`

## Use

- Slash: `/teach-me`
- Or: “teach me [topic]”, “help me retain…”, “quiz me until I can teach this”

## Layout

```text
teach-me/
  SKILL.md
  README.md
  references/
    adult-learning-principles.md
    teach-back-rubric.md
    session-templates.md
```
